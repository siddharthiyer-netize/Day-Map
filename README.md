# The Day Map

A standalone, local-first recreation of the Day Map productivity web app.

## Features
- Daily plan and task blocks
- Focus timer with presets and custom duration
- Insights and charts
- Daily journal
- Themes
- Local browser storage

## Publish with GitHub Pages
1. Create a public GitHub repository named `the-day-map`.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.

No backend or API key is required.
